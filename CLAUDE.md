# Семь планет до Солнца

Квест-сайт в подарок девушке (Настя). Повода нет, это просто сюрприз. Хостится на GitHub Pages: https://blanksecond.github.io/game2/

Общаться с владельцем на русском.

## Что это
Один файл `index.html`: живая 3D-система на Three.js r160 (importmap с jsdelivr) и анимации на GSAP 3.12.5 (cdnjs).
Шрифты Unbounded, Onest, JetBrains Mono с Google Fonts.
Путешествие по Солнечной системе: 6 планет с заданиями, в конце Солнце. Все планеты открыты сразу, порядок любой.
Главный экран — вращающаяся система; клик по планете → перелёт камеры, стеклянная панель с заданием.
На телефоне камера повёрнута на 90°, чтобы орбиты шли по высоте экрана, и орбиты плотнее (`DM`).
Прелоадер со счётчиком, буквы заголовков выезжают из-под маски (`split`/`reveal`), курсор-кольцо на компьютере.
Если WebGL или библиотеки не загрузились за 15 секунд, работает плоский режим (`bootFlat`, `renderFlat`).
Каждая глава в 2–3 этапа, чтобы всё прохождение заняло примерно час, а не 15 минут.

Главы (`CONFIG.planets[].type`), задание связано с настоящим фактом о планете:
1. `venus` — роза Венеры (точки по реальной орбите за 8 лет), потом зеркальное послание, ответ — её имя
2. `earth` — офлайн: загадка → записка дома (`notes`, можно несколько по цепочке)
3. `mars` — марсоход: собрать программу стрелками, 3 участка (`MARS`), задержка сигнала, голубой закат
4. `jupiter` — мемори: спутники Галилея (снимок ↔ имя), потом «наши спутники» (`ours`: фото + подпись)
5. `saturn` — шифровальные кольца (сдвиг Цезаря): разминка `warmup`, потом `secret` с ключом 6
6. `neptune` — Золотая пластинка: повтори мелодию (`rounds`), потом история пластинки и ссылка на песню (`song`)
7. `sun` — сложить фразу из слов 1–6, письмо, финальный купон

После каждой главы открытка: слово-фрагмент фразы и купон-скретч.

Дизайн: тёмный космос, стекло, солнечное золото `#ffb547`, огромные широкие заголовки (референсы владельца: motionsites Celestix, 35mm, Naya, Madar).
Текстуры планет для 3D в `photos/textures/` (Solar System Scope, CC BY 4.0, указано в «Маршруте»).
Снимки NASA в `photos/planets/` для открыток, мемори и плоского режима (источники в `credits.json`, общественное достояние).

Встроенный браузер приложения троттлит requestAnimationFrame, когда окно не в фокусе: анимации там ползут.
Для проверки удобнее headless Chrome по CDP (скрипт со скриншотами по шагам).

## Правила
- Все тексты, фото и ответы лежат в блоке `CONFIG` в начале скрипта.
- Ответы на вход и офлайн-записку хранятся только как SHA-256 от нормализованной строки (нижний регистр, ё→е, только буквы и цифры). Открытым текстом их в код не писать.
- Хеш нового ответа делается в режиме разработчика: `index.html#dev` (там же все главы, «отметить всё пройденным» и сброс прогресса).
- Даты из прошлого проекта не повторять: владелец не хочет повторов.
- Прогресс хранится в localStorage (`nebo-progress-v2`: `gate`, `done`, `scratched`).
- Старый репозиторий `Blanksecond/game` не трогать.
- Коммиты подписывать: `Claude <noreply@anthropic.com>`.
